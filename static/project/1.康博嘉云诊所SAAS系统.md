# 康博嘉云诊所医疗SAAS系统

## 简介

面向国内全科诊所和中医诊所的民营医疗 SaaS 系统，为诊所提供预约、看诊（病历、医嘱）、收费、发药、医嘱执行和库房进销存的全流程服务。系统采用单体架构，覆盖病人线下看病的完整业务闭环。

## 技术架构

- **后端**：Spring Boot、Spring MVC、MyBatis、PostgreSQL、Redis、Easy Excel、Fast DFS、Scala
- **前端**：jQuery、Vue、Ant Design

## 核心功能设计

### 病历附件扫码上传

**业务场景**：医生在PC端接诊时，需要将患者的纸质病历、检查报告、处方单等附件快速录入系统。

**技术方案**：

1. **二维码生成服务**
   - 后端生成包含上传URL、临时token、病历ID的二维码
   - Token有效期5分钟，使用Redis存储，支持一次性使用

2. **文件上传流程**
   - 手机扫码 → 选择/拍摄文件 → 上传到FastDFS → 返回文件ID
   - 前端轮询查询上传状态，获取文件ID后关联病历

3. **数据存储设计**
   - 附件表：存储附件元数据（病历ID、文件ID、文件类型、上传时间）
   - FastDFS存储实际文件，支持图片、PDF等多种格式

4. **技术实现**
   - FastDFS：分布式文件存储
   - Redis：存储临时token和上传状态
   - 定时任务：清理过期token和未关联文件

### 九种外治处方策略模式设计

**设计思路**：使用策略模式解耦不同外治处方类型的执行逻辑，便于扩展和维护。

**类图结构**：

```plaintext
TreatmentExecutionStrategy (策略接口)
├── defineType(): 外治类型枚举
├── validateParams(): 参数校验
├── calculateFee(): 费用计算
├── buildExecutionRecord(): 构建执行记录
└── execute(): 执行治疗

BaseTreatmentStrategy (抽象基类)
├── 公共参数校验逻辑
├── 公共费用计算逻辑
└── 模板方法：execute()

NineTreatmentStrategy implementations:
├── AcupunctureStrategy (针灸)
├── CuppingStrategy (拔罐)
├── ScrapingStrategy (刮痧)
├── MoxibustionStrategy (艾灸)
├── MassageStrategy (推拿)
├── HotCompressStrategy (热敷)
├── FumigationStrategy (熏蒸)
├── AcupointPatchStrategy (穴位贴敷)
└── ExternalMedicineStrategy (中药外敷)

TreatmentStrategyFactory (策略工厂)
├── registerStrategy(): 注册策略
├── getStrategy(): 获取策略
└── Map<TreatmentType, Strategy> 缓存
```

**关键代码结构**：

```java
// 1. 外治类型枚举
public enum TreatmentType {
    ACUPUNCTURE("针灸"), CUPPING("拔罐"), SCRAPING("刮痧"),
    MOXIBUSTION("艾灸"), MASSAGE("推拿"), HOT_COMPRESS("热敷"),
    FUMIGATION("熏蒸"), ACUPOINT_PATCH("穴位贴敷"),
    EXTERNAL_MEDICINE("中药外敷");
}

// 2. 策略接口
public interface TreatmentExecutionStrategy {
    TreatmentType defineType();
    void validateParams(Map<String, Object> params);
    BigDecimal calculateFee(Map<String, Object> params);
    TreatmentExecutionRecord buildRecord(Long orderId, Map<String, Object> params);
    void execute(TreatmentExecutionRecord record);
}

// 3. 抽象基类（模板方法）
public abstract class BaseTreatmentStrategy implements TreatmentExecutionStrategy {
    @Override
    public void execute(TreatmentExecutionRecord record) {
        validateParams(record.getParams());
        // ... 公共执行逻辑
    }
}

// 4. 具体策略实现（以针灸为例）
@Component
public class AcupunctureStrategy extends BaseTreatmentStrategy {
    @Override
    public TreatmentType defineType() {
        return TreatmentType.ACUPUNCTURE;
    }
    
    @Override
    public Map<String, Object> getDefaultParams() {
        return Map.of("duration", 30, "needleSpec", "0.30x40mm");
    }
}

// 5. 策略工厂
@Component
public class TreatmentStrategyFactory {
    private final Map<TreatmentType, TreatmentExecutionStrategy> strategies = new HashMap<>();
    
    @PostConstruct
    public void init() {
        // Spring自动注入所有策略，按类型注册
        strategies.put(strategy.defineType(), strategy);
    }
    
    public TreatmentExecutionStrategy getStrategy(TreatmentType type) {
        return strategies.get(type);
    }
}
```

```sql
-- 外治处方基础表
CREATE TABLE treatment_prescription (
    id BIGSERIAL PRIMARY KEY,
    order_id BIGINT NOT NULL,
    treatment_type VARCHAR(20) NOT NULL,
    params JSONB NOT NULL,  -- 各类型扩展参数
    fee DECIMAL(10,2),
    status VARCHAR(20)
);

-- 外治执行记录表
CREATE TABLE treatment_execution (
    id BIGSERIAL PRIMARY KEY,
    prescription_id BIGINT NOT NULL,
    executor_id BIGINT,
    execute_time TIMESTAMP,
    result JSONB,  -- 执行结果（穴位反馈、时长记录等）
    status VARCHAR(20)
);
```
